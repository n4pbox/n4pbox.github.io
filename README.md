# 📜 Regras do Servidor GMOD

Bem-vindo ao servidor! Para garantir a organização e a diversão de todos, é fundamental o cumprimento das diretrizes abaixo.

---

## 📊 Índice de Punições

| Símbolo | Punição | Detalhes |
| :---: | :--- | :--- |
| 💣 | **Ban Permanente (Irrevogável)** | Sem chance de revogação alguma. |
| 🔴 | **Ban Permanente** | Banimento definitivo. |
| 🟠 | **Ban Temporário** | Afastamento por tempo determinado. |
| 🟡 | **Jail / Kick / Mute** | Prisão, expulsão ou silenciamento. |
| 🟢 | **Warn** | Aviso formal. |

---

## §1 - Comportamento

* **1.1** - É **VETADO** qualquer tipo de preconceito (como por exemplo: Racismo, homofobia, etc.). 💣 
* **1.2** - É **repudiado** comportamentos tóxicos/ilegais no servidor. Exemplos incluem, mas não se limitam a: perseguir alguém, proferir xingamentos muito pesados e incentivar o suicídio. 🔴 ou 💣 
* **1.3** - É **VETADO** qualquer tipo de perseguição a algum jogador no servidor. 💣 

## §2 - Conteúdo

* **2.1** - É **VETADO** qualquer tipo de conteúdo *NSFW* (Not Safe For Work). Exemplos incluem, mas não se limitam a: 💣 
  * Skins do *outfitter*
  * Sprays
  * Entre outros meios.

## §3 - Wiremod / E2

* **3.1** - Não é permitido o uso de E2 com o objetivo de eliminar ou incapacitar o jogador de maneira repetitiva e injusta (coisas como: *spawnkill*, *blinder*, *jail*, etc.). 🟡 *(Pode progredir para 🟠)*

## §4 - Crash

* **4.1** - É completamente **proibido e repudiado** causar instabilidade ou crashar o servidor de maneira intencional independentemente da forma. Por exemplo: 💣
  * Spam de *props*
  * E2 Malicioso
  * Bugs de *addons*

## §5 - Combate

* **5.1** - É **VETADO** qualquer tipo de *prop push* ou *prop kill* sem consentimento. 🟢 *(Pode progredir para 🟡)*
